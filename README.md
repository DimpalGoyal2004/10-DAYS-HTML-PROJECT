# Beginner Web Projects

This repository contains a collection of simple beginner-friendly web projects built while learning and practicing HTML, CSS and JavaScript.

## Projects

### 1. Calculator App
A simple calculator that performs basic arithmetic operations.

**Technologies:** HTML, CSS, JavaScript

### 2. Digital Clock
A digital clock that displays the current time and updates automatically.

**Technologies:** HTML, CSS, JavaScript

### 3. Notes App
A simple notes application for creating and managing notes.

**Technologies:** HTML, CSS, JavaScript

### 4. Todo List
A simple Todo List application for adding and managing tasks.

**Technologies:** HTML, CSS, JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

These projects were created to practice frontend development concepts and improve my understanding of HTML, CSS and JavaScript.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Go to any project folder.
4. Open its HTML file in a web browser.
